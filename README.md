# 地层流体识别方法开源实现

本仓库是论文中地层流体识别方法的代码实现，用于公开模型结构、训练流程和方法说明。由于原始油田测井数据涉及保密信息，仓库不包含任何真实井数据、训练缓存、模型权重或训练日志。

![Workflow](pythonProject/docs/assets/workflow.png)

## 方法简介

该方法面向测井曲线驱动的地层流体类型识别任务，整体流程包括五个阶段：

1. 数据输入：读取 GR、RT、AC、SP 等测井曲线。
2. 双流转换：一条分支进行时频变换，另一条分支计算物性参数。
3. 双流特征提取：使用 MDSC 模块提取时频图谱视觉特征，使用 MLP/注意力模块提取物性先验特征。
4. 跨模态融合：将视觉特征与物性特征拼接、交互和校准。
5. 分类输出：输出油层、水层、干层、差油层、油水层五类概率。

## 开源范围

本仓库保留：

- 模型结构代码
- 训练入口代码
- 数据加载与预处理接口
- 流程图和方法说明
- 论文方法复现所需的代码框架

本仓库不包含：

- 真实油田井数据
- 由真实数据生成的时频图谱缓存
- 训练日志
- TensorBoard 文件
- 模型权重文件
- 涉及具体井名、具体深度或油田业务信息的报告

## 目录结构

```text
pythonProject/
  configs/                 训练参数配置
  data/                    数据加载、类别定义和预处理接口
  docs/                    流程图和数据隐私说明
  main/                    当前论文方法的训练入口
  models/                  MDSC、TAM、损失函数等模型实现
```

当前仓库只保留论文最终方法相关代码。早期尝试过的六条测井曲线模型、小波分解独立模型、旧版推理脚本、历史数据生成工具和重复实验程序没有放入主分支，以避免和论文方法混淆。

## 论文实验结果

在论文实验使用的私有测试集上，历史最佳测试结果为：

- 测试准确率：92.24%
- 测试 Macro-F1：0.898

该结果仅用于说明论文实验表现。由于真实油田数据、训练缓存、模型权重和日志未公开，公开仓库中的代码不能直接复现上述数值。使用者需要替换为自己的数据后重新训练、验证并报告实验结果。

## 环境配置

建议使用 Python 3.10 或更高版本。

安装基础依赖：

```bash
pip install torch numpy scikit-learn
```

如需自行扩展时频图谱生成或绘制分析图，可根据自己的数据处理脚本补充安装 `matplotlib`、`pywavelets` 等依赖。

## 数据准备

真实数据未随仓库发布。使用者需要准备自己的井曲线数据，并按训练脚本要求生成图谱缓存。

推荐的原始数据组织方式：

```text
pythonProject/
  train_wells/     训练井数据，用户自行提供
  val_wells/       验证井数据，用户自行提供
  test_wells/      测试井数据，用户自行提供
```

推荐的缓存数据组织方式：

```text
pythonProject/
  optimized_patch_data/
    train_spectrograms/
    valid_spectrograms/
    test_spectrograms/
    meta/
```

每个样本需要包含：

- 时频图谱张量
- 辅助物性特征向量
- 流体类型标签
- 样本来源标识
- 深度索引或样本序号

流体类别约定：

```text
0: 油层
1: 水层
2: 干层
3: 差油层
4: 油水层
```

## 训练

进入代码目录：

```bash
cd pythonProject
```

运行当前推荐训练入口：

```bash
python main/run_final_optimized_training.py
```

可通过环境变量控制训练轮数和随机种子：

```bash
NUM_EPOCHS=700 PY_SEED=42 python main/run_final_optimized_training.py
```

训练脚本默认读取：

```text
optimized_patch_data/
```

如果该目录不存在，需要先使用自己的数据生成缓存，或修改数据加载器以适配自己的数据格式。

## 推理与复现

仓库不提供基于私有数据训练得到的模型权重，也不保留旧版推理脚本。复现时建议先使用 `main/run_final_optimized_training.py` 在自有数据上训练，再基于 `models/lightweight_mdsc_tam.py` 中的模型结构编写与自己数据格式匹配的推理脚本。
